# noctalia-plugins

Noctalia plugins by [neoscaler](https://github.com/neoscaler). Add the repo as a plugin source:

```sh
noctalia msg plugins source add neoscaler git https://github.com/neoscaler/noctalia-plugins
```

| Plugin | Description |
| --- | --- |
| [`charge-mode`](charge-mode/) | Control-center tile that cycles the battery charge type: conservation, normal, fast charge. |
| [`tibber`](tibber/) | Tibber electricity prices (demo data): bar widget, panel and desktop widget with the cheapest and most expensive time of the day. |
